🥚 Egg Catcher Game

A simple arcade game developed using Python and Tkinter.

Features:
• Falling eggs
• Basket movement
• Score system
• Lives system
• Collision detection
• Increasing difficulty

Technologies:
• Python
• Tkinter
• Random
• Itertools

How to Run:
1. Install Python.
2. Download the project.
3. Run egg_catcher.py.
